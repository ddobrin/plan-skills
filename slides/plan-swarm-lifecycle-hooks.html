Vulnerability Analysis

The Failure Modes of Unhardened Swarms

Where Autonomous Agent Teams Drift Under High Cognitive Load

⚠

1. Commit Boundary Leak

The Invariant: Only starter may commit; only after a green audit and explicit user approval.

The Failure: An ambitious engineer subagent completes a task and calls git commit -m 'done' directly, bypassing the auditor, the implementation-validator, and the human gate.

🚫

2. Read-Only Code Contamination

The Invariant: architect, auditor, and validators are read-only on repo source.

The Failure: During analysis, an architect tests a theory by editing src/auth.ts or adding a mock class. The implementation plan becomes based on dirty, modified state rather than clean HEAD.

🤖

3. The Anti-Shortcut Illusion

The Invariant: No faked mocks, skipped tests, or deferred TODO comments.

The Failure: An engineer hits a tricky edge case, adds it.skip() or a // TODO: implement later, gets a green suite, and marks the task [x]. The auditor must spend extra tokens hunting it down.

🔄

4. State Machine Amnesia

The Invariant: state.json is the single source of truth for phase, gate, and quorum data.

The Failure: An agent creates spec.md or plan.md but omits updating state.json. A resumed session re-infers state from filesystem heuristics and restarts completed phases.

🛑

5. Premature Loop Termination

The Invariant: The supervisor runs the loop until all execution groups land and verify.

The Failure: After Group 1, the model returns a friendly summary and terminates (model_stop), leaving Groups 2 and 3 unexecuted and the milestone half-built.

💥

6. Catastrophic Git Commands

The Invariant: Non-destructive version control actions only.

The Failure: Confused by a merge conflict or detached HEAD, an agent runs git reset --hard or git clean -fdx, wiping uncommitted plans and characterization tests.

Input / Output Contract (JSON over Stdin/Stdout)

Hook commands execute as subprocesses receiving structured system metadata:

  • conversationId, workspacePaths, transcriptPath, stepIdx
  • toolCall: { "name": "run_command", "args": { ... } }

And emitting authoritative decisions:

{
  "decision": "deny",
  "reason": "Invariant violation: only starter may commit."
}

Core Principles for Swarm Hooks

  • Deterministic: Written in Python 3 stdlib without external API or heavy dependencies.
  • Sub-Millisecond: Executes in <30ms, introducing zero perceived latency to the developer or agent.
  • Fail-Safe: Default to allow for routine actions, hard-deny for structural invariant breaches.
  • State-Grounded: Queries graph.json and state.json directly on disk.

PreToolUse Hook

Hook 1: Git Commit Authority Guard

Enforcing the Sole Commit Authority of the Starter / Supervisor

Event: PreToolUse Matcher: run_command Target: git commit

The Core Invariant: Commits belong strictly to starter after an auditor passes and the human grants explicit permission. Subagents have no user turn and must never commit.

plugins/plan/lib/hooks/guard_commit.py 
#!/usr/bin/env python3
"""PreToolUse Hook: Enforce Git Commit Authority in the Plan Swarm.

Swarm Invariant:
  'Only starter runs git commit; it is the only node holding a user-facing
   turn in which approval can be obtained.'
  Commits are permitted ONLY when:
    1. The active agent is 'starter' (or user acting directly).
    2. The current execution group in state.json has audit == 'passed'.
    3. The human commit gate has state == 'approved'.
"""

import json
import os
import re
import sys
from pathlib import Path

def find_active_milestone_state(workspace_root: Path) -> tuple[Path | None, dict | None]:
    milestones_dir = workspace_root / "plans" / "active_milestones"
    if not milestones_dir.is_dir():
        return None, None
    for item in milestones_dir.iterdir():
        if item.is_dir():
            state_file = item / "state.json"
            if state_file.is_file():
                try:
                    with state_file.open("r", encoding="utf-8") as f:
                        return state_file, json.load(f)
                except Exception:
                    pass
    return None, None

def main():
    try:
        payload = json.load(sys.stdin)
    except Exception:
        print(json.dumps({"decision": "allow"}))
        return

    tool_call = payload.get("toolCall", {})
    name = tool_call.get("name", "")
    args = tool_call.get("args", {})

    if name != "run_command":
        print(json.dumps({"decision": "allow"}))
        return

    cmd = args.get("CommandLine", "").strip()
    is_commit = bool(re.search(r"\bgit\s+commit\b", cmd))
    if not is_commit:
        print(json.dumps({"decision": "allow"}))
        return

    # 1. Identify Workspace & Current Agent Role
    ws_paths = payload.get("workspacePaths", [])
    ws_root = Path(ws_paths[0]) if ws_paths else Path.cwd()

    role_marker = ws_root / ".agents" / "current_role.txt"
    current_role = os.environ.get("PLAN_SWARM_ROLE", "")
    if not current_role and role_marker.is_file():
        current_role = role_marker.read_text(encoding="utf-8").strip()

    # If an engineer or auditor attempts to commit directly -> HARD DENY
    if current_role and current_role not in ("starter", "supervisor"):
        out = {
            "decision": "deny",
            "reason": (
                f"Plan Swarm Invariant Violation: Role '{current_role}' is forbidden from "
                "running 'git commit'. Only 'starter' holds the user-facing turn required "
                "for commit approval. Hand work back to starter."
            )
        }
        print(json.dumps(out))
        return

    # 2. Check state.json for Audit and Gate Approval
    state_file, state = find_active_milestone_state(ws_root)
    if not state:
        out = {
            "decision": "ask",
            "reason": "Git commit requested outside of an active milestone. Confirm execution?"
        }
        print(json.dumps(out))
        return

    groups = state.get("groups", [])
    active_group = next((g for g in reversed(groups) if g.get("committed") is None), None)

    if active_group:
        audit_status = active_group.get("audit")
        if audit_status != "passed":
            out = {
                "decision": "deny",
                "reason": (
                    f"Plan Swarm Gate Blocked: Cannot commit Execution Group {active_group.get('id')}! "
                    f"Audit status is '{audit_status}', expected 'passed'. "
                    "Auditor verification must succeed before committing."
                )
            }
            print(json.dumps(out))
            return

    gates = state.get("gates", [])
    commit_gate = next((g for g in gates if g.get("id") == "commit"), None)
    if commit_gate and commit_gate.get("state") != "approved":
        out = {
            "decision": "force_ask",
            "reason": "Human Commit Gate: Auditor passed. Confirm committing this verified group?"
        }
        print(json.dumps(out))
        return

    print(json.dumps({"decision": "allow"}))

if __name__ == "__main__":
    main()
PreToolUse Hook

Hook 2: Source Code Write Boundary Barrier

Locking Down Read-Only Roles Outside of plans/

Event: PreToolUse Matcher: write_to_file | replace_file_content | notebook_edit Enforces: must_not_write <repo source>

The Core Invariant: architect, auditor, product-owner, and validators are read-only on repository source code. They may only write artifacts under plans/.

plugins/plan/lib/hooks/guard_source_writes.py 
#!/usr/bin/env python3
"""PreToolUse Hook: Enforce Read-Only Source Code Boundaries.

Swarm Invariant:
  'Only engineer and simplifier write repository source.'
  Roles such as 'architect', 'visual-architect', 'auditor', 'product-owner',
  and all validators are strictly READ-ONLY on source code and may only
  write artifacts under 'plans/'.
"""

import json
import os
import sys
from pathlib import Path

READ_ONLY_ROLES = {
    "architect",
    "visual-architect",
    "auditor",
    "product-owner",
    "visual-product-owner",
    "spec-validator",
    "plan-validator",
    "implementation-validator",
    "geap-spec-validator",
    "geap-plan-validator",
    "spec-deliberator",
    "plan-deliberator"
}

WRITE_TOOLS = {
    "write_to_file",
    "replace_file_content",
    "notebook_edit"
}

def main():
    try:
        payload = json.load(sys.stdin)
    except Exception:
        print(json.dumps({"decision": "allow"}))
        return

    tool_call = payload.get("toolCall", {})
    tool_name = tool_call.get("name", "")
    args = tool_call.get("args", {})

    if tool_name not in WRITE_TOOLS:
        print(json.dumps({"decision": "allow"}))
        return

    target_path_str = args.get("TargetFile") or args.get("AbsolutePath") or args.get("NotebookPath") or ""
    if not target_path_str:
        print(json.dumps({"decision": "allow"}))
        return

    target_path = Path(target_path_str).resolve()
    ws_paths = payload.get("workspacePaths", [])
    ws_root = Path(ws_paths[0]).resolve() if ws_paths else Path.cwd().resolve()

    try:
        rel_path = target_path.relative_to(ws_root)
    except ValueError:
        print(json.dumps({"decision": "allow"}))
        return

    role_marker = ws_root / ".agents" / "current_role.txt"
    current_role = os.environ.get("PLAN_SWARM_ROLE", "")
    if not current_role and role_marker.is_file():
        current_role = role_marker.read_text(encoding="utf-8").strip()

    is_plan_artifact = str(rel_path).startswith("plans/") or str(rel_path).startswith(".agents/")

    if current_role in READ_ONLY_ROLES and not is_plan_artifact:
        out = {
            "decision": "deny",
            "reason": (
                f"Plan Swarm Boundary Violation: Role '{current_role}' is read-only on repository source! "
                f"Attempted to edit '{rel_path}'. This role is restricted to authoring artifacts under plans/. "
                "Only 'engineer' and 'simplifier' may write repository code."
            )
        }
        print(json.dumps(out))
        return

    print(json.dumps({"decision": "allow"}))

if __name__ == "__main__":
    main()
PostToolUse Hook

Hook 3: Anti-Shortcut & Auto-Format Guard

Instant Static Detection for Deferred Work, TODOs, and Mutilated Tests

Event: PostToolUse Matcher: * Hunts: TODO, FIXME, xit, test.skip, @Ignore

The Core Invariant: Catches work that looks green but is faked or skipped before the engineer concludes their turn, saving expensive multi-agent audit loops.

plugins/plan/lib/hooks/auto_format_and_shortcut_scan.py 
#!/usr/bin/env python3
"""PostToolUse Hook: Instant Anti-Shortcut Scan & Auto-Formatter.

Swarm Invariant:
  'Auditor hunts the shortcuts that fake a green build: TODOs, placeholders,
   deferred work, skipped or gutted tests, hardcoded expected outputs.'
This hook scans modified files immediately after edit to provide instant
feedback before the auditor even needs to run.
"""

import json
import re
import subprocess
import sys
from pathlib import Path

SHORTCUT_PATTERNS = [
    (r"\bTODO\b", "TODO placeholder found"),
    (r"\bFIXME\b", "FIXME deferred work found"),
    (r"\bHACK\b", "HACK workaround found"),
    (r"\b(?:it\.skip|test\.skip|xit|xtest)\b", "Skipped test detected (test integrity compromised)"),
    (r"@pytest\.mark\.skip", "Skipped pytest detected"),
    (r"@Ignore\b", "Ignored test detected"),
    (r"assert\s+(?:True|1\s*==\s*1|False)", "Trivial or fake assertion detected")
]

def main():
    try:
        payload = json.load(sys.stdin)
    except Exception:
        print("{}")
        return

    ws_paths = payload.get("workspacePaths", [])
    ws_root = Path(ws_paths[0]) if ws_paths else Path.cwd()

    try:
        res = subprocess.run(
            ["git", "status", "--porcelain"],
            cwd=ws_root,
            capture_output=True,
            text=True,
            timeout=5
        )
        modified = []
        for line in res.stdout.splitlines():
            if line.startswith((" M", "M ", "??", "A ")):
                filepath = line[3:].strip()
                if not filepath.startswith("plans/") and not filepath.startswith("."):
                    modified.append(ws_root / filepath)
    except Exception:
        print("{}")
        return

    alerts = []
    for fpath in modified:
        if not fpath.is_file() or fpath.suffix in (".png", ".jpg", ".bin", ".pyc"):
            continue
        try:
            content = fpath.read_text(encoding="utf-8", errors="ignore")
            for idx, line in enumerate(content.splitlines(), start=1):
                for pattern, msg in SHORTCUT_PATTERNS:
                    if re.search(pattern, line):
                        alerts.append(f"{fpath.relative_to(ws_root)}:{idx} - {msg}")
        except Exception:
            continue

    agents_dir = ws_root / ".agents"
    agents_dir.mkdir(exist_ok=True)
    alerts_file = agents_dir / "anti_shortcut_alerts.json"

    if alerts:
        alerts_file.write_text(json.dumps({
            "detected_shortcuts": alerts,
            "count": len(alerts)
        }, indent=2), encoding="utf-8")
    elif alerts_file.is_file():
        alerts_file.unlink()

    for fpath in modified:
        if fpath.suffix in (".ts", ".js", ".json", ".md") and subprocess.run(["which", "prettier"], capture_output=True).returncode == 0:
            subprocess.run(["prettier", "--write", str(fpath)], capture_output=True, timeout=5)
        elif fpath.suffix == ".py" and subprocess.run(["which", "black"], capture_output=True).returncode == 0:
            subprocess.run(["black", "-q", str(fpath)], capture_output=True, timeout=5)

    print("{}")

if __name__ == "__main__":
    main()
PostToolUse Hook

Hook 4: State Machine & Quorum Synchronizer

Automatic, Zero-Drift Indexing of Swarm Artifacts into state.json

Event: PostToolUse Matcher: * Single Source of Truth: state.json

The Core Invariant: Eliminates LLM amnesia. As soon as spec.md, plan.md, AUDIT_*.md, or validation reports are written, state.json is automatically parsed and updated.

plugins/plan/lib/hooks/sync_state.py 
#!/usr/bin/env python3
"""PostToolUse Hook: Keep state.json in Perfect Sync with Swarm Artifacts.

Swarm Contract:
  'state.json is the run\'s declared state — phase, gate decisions, per-node
   status and reports, per-group task and commit status. starter reads this
   to resume rather than inferring the phase from which files exist.'
"""

import json
import re
import sys
from datetime import datetime, timezone
from pathlib import Path

def parse_spec_validation(report_path: Path) -> dict:
    if not report_path.is_file():
        return {}
    text = report_path.read_text(encoding="utf-8")
    confirmed = len(re.findall(r"\*\*Confirmed Findings:\*\*\s*(\d+)", text))
    status = "passed" if "Verdict: PASS" in text or confirmed == 0 else "findings"
    return {
        "status": status,
        "report": str(report_path.name),
        "updated": datetime.now(timezone.utc).isoformat()
    }

def parse_audit_report(audit_path: Path) -> str:
    if not audit_path.is_file():
        return "not-reached"
    text = audit_path.read_text(encoding="utf-8")
    if "Overall Status:** PASS" in text or "Overall Status: PASS" in text:
        return "passed"
    elif "Overall Status:** FAIL" in text or "Overall Status: FAIL" in text:
        return "failed"
    return "running"

def main():
    try:
        payload = json.load(sys.stdin)
    except Exception:
        print("{}")
        return

    ws_paths = payload.get("workspacePaths", [])
    ws_root = Path(ws_paths[0]) if ws_paths else Path.cwd()

    milestones_dir = ws_root / "plans" / "active_milestones"
    if not milestones_dir.is_dir():
        print("{}")
        return

    for item in milestones_dir.iterdir():
        if not item.is_dir():
            continue
        moniker = item.name
        state_file = item / "state.json"
        if not state_file.is_file():
            continue

        try:
            with state_file.open("r", encoding="utf-8") as f:
                state = json.load(f)
        except Exception:
            continue

        changed = False

        # 1. Check spec.md
        spec_file = item / "spec.md"
        if spec_file.is_file() and state.get("nodes", {}).get("product-owner", {}).get("status") != "done":
            state.setdefault("nodes", {}).setdefault("product-owner", {})["status"] = "done"
            state["nodes"]["product-owner"]["artifact"] = "spec.md"
            changed = True

        # 2. Check spec-validation.md
        spec_val_file = item / "adversarial-reviews" / "spec-validation.md"
        if spec_val_file.is_file():
            val_data = parse_spec_validation(spec_val_file)
            current_status = state.get("nodes", {}).get("spec-validator", {}).get("status")
            if current_status != val_data.get("status"):
                state.setdefault("nodes", {})["spec-validator"] = {
                    **state.get("nodes", {}).get("spec-validator", {}),
                    **val_data
                }
                changed = True

        # 3. Check plan.md
        plan_file = item / "plan.md"
        if plan_file.is_file() and state.get("nodes", {}).get("architect", {}).get("status") != "done":
            state.setdefault("nodes", {}).setdefault("architect", {})["status"] = "done"
            state["nodes"]["architect"]["artifact"] = "plan.md"
            changed = True

        # 4. Check audit report
        audit_dir = ws_root / "plans" / "audit"
        if audit_dir.is_dir():
            for af in audit_dir.glob("AUDIT_*.md"):
                audit_verdict = parse_audit_report(af)
                groups = state.get("groups", [])
                for g in groups:
                    if g.get("committed") is None and g.get("audit") != audit_verdict:
                        g["audit"] = audit_verdict
                        changed = True

        if changed:
            state["updated"] = datetime.now(timezone.utc).isoformat()
            with state_file.open("w", encoding="utf-8") as f:
                json.dump(state, f, indent=2)

    print("{}")

if __name__ == "__main__":
    main()
Stop Hook

Hook 5: Milestone Completion & Anti-Early-Exit Guard

Preventing Premature Termination While Work Remains Incomplete

Event: Stop Trigger: model_stop Output: decision: continue

The Core Invariant: If the model attempts to exit while execution group tasks are still unchecked (- [ ]) or the auditor reported a failure, this hook vetoes termination and re-enters the loop with actionable guidance.

plugins/plan/lib/hooks/check_milestone_completion.py 
#!/usr/bin/env python3
"""Stop Hook: Milestone Completion & Anti-Early-Exit Guard.

Swarm Invariant:
  The agent execution loop must NOT terminate prematurely if:
  1. There are incomplete tasks in the active execution group in plan.md.
  2. The auditor has returned a FAIL verdict that has not been resolved.
  3. A validator run left confirmed defects or untriaged single-vote findings.
  4. The supervisor hasn't completed all required gates.
"""

import json
import re
import sys
from pathlib import Path

def main():
    try:
        payload = json.load(sys.stdin)
    except Exception:
        print(json.dumps({"decision": "allow"}))
        return

    reason = payload.get("terminationReason", "")
    if reason not in ("model_stop", ""):
        print(json.dumps({"decision": "allow"}))
        return

    ws_paths = payload.get("workspacePaths", [])
    ws_root = Path(ws_paths[0]) if ws_paths else Path.cwd()

    milestones_dir = ws_root / "plans" / "active_milestones"
    if not milestones_dir.is_dir():
        print(json.dumps({"decision": "allow"}))
        return

    for item in milestones_dir.iterdir():
        if not item.is_dir():
            continue
        moniker = item.name
        state_file = item / "state.json"
        plan_file = item / "plan.md"

        if not state_file.is_file():
            continue

        try:
            with state_file.open("r", encoding="utf-8") as f:
                state = json.load(f)
        except Exception:
            continue

        phase = state.get("phase", "")

        # Check for unfulfilled tasks during construction phase (Phase 4)
        if phase.startswith("4") and plan_file.is_file():
            plan_text = plan_file.read_text(encoding="utf-8")
            unchecked = re.findall(r"-\s*\[\s*\]\s*(Task\s*[\d\w\.]+:[^
]+)", plan_text)
            if unchecked:
                out = {
                    "decision": "continue",
                    "reason": (
                        f"Milestone '{moniker}' cannot stop! Phase 4 has {len(unchecked)} incomplete task(s):\n"
                        f"  -> {unchecked[0]}\n"
                        "Dispatch an engineer to finish remaining tasks before completing."
                    )
                }
                print(json.dumps(out))
                return

        # Check for unresolved audit failure
        groups = state.get("groups", [])
        active_group = next((g for g in reversed(groups) if g.get("committed") is None), None)
        if active_group and active_group.get("audit") == "failed":
            rounds = active_group.get("audit_rounds", 1)
            if rounds < 3:
                out = {
                    "decision": "continue",
                    "reason": (
                        f"Milestone '{moniker}' cannot stop with a FAILING audit!\n"
                        f"Execution Group {active_group.get('id')} failed verification. "
                        "Dispatch engineer to fix the reported defects under TDD."
                    )
                }
                print(json.dumps(out))
                return

        # Check for unvalidated specs or plans if phase suggests advancement
        nodes = state.get("nodes", {})
        spec_val = nodes.get("spec-validator", {})
        if spec_val.get("status") == "findings":
            out = {
                "decision": "continue",
                "reason": (
                    f"Milestone '{moniker}' has outstanding confirmed findings in spec-validation.md. "
                    "Fold hardenings into spec.md before proceeding."
                )
            }
            print(json.dumps(out))
            return

    print(json.dumps({"decision": "allow"}))

if __name__ == "__main__":
    main()
PreToolUse Hook

Hook 6: Destructive Command Firewall

Safeguarding Repository History and Uncommitted Work

Event: PreToolUse Matcher: run_command Blocks: git push -f, reset --hard, clean -fdx

The Core Invariant: Catastrophic actions that destroy history or uncommitted characterization tests are intercepted and denied before execution.

plugins/plan/lib/hooks/guard_destructive_commands.py 
#!/usr/bin/env python3
"""PreToolUse Hook: Destructive Command Firewall.

Protects against catastrophic repository actions such as forced branch overwrites,
hard resets, and recursive un-staged wipes.
"""

import json
import re
import sys

DESTRUCTIVE_PATTERNS = [
    (r"\bgit\s+push\b.*\b(?:--force|-f)\b", "Force-pushing branches is strictly prohibited in the swarm."),
    (r"\bgit\s+reset\s+--hard\b", "git reset --hard destroys uncommitted working tree state."),
    (r"\bgit\s+clean\b.*-[a-zA-Z]*f", "git clean -f deletes untracked files without confirmation."),
    (r"\brm\s+-[a-zA-Z]*r[a-zA-Z]*f\s+(?:/|\*|~|\.\.)", "Dangerous recursive directory deletion attempted."),
    (r"\bgit\s+branch\s+-[dD]\s+(?:main|master|prod|release)", "Deletion of primary branches is prohibited.")
]

def main():
    try:
        payload = json.load(sys.stdin)
    except Exception:
        print(json.dumps({"decision": "allow"}))
        return

    tool_call = payload.get("toolCall", {})
    if tool_call.get("name") != "run_command":
        print(json.dumps({"decision": "allow"}))
        return

    cmd = tool_call.get("args", {}).get("CommandLine", "").strip()

    for pattern, warning in DESTRUCTIVE_PATTERNS:
        if re.search(pattern, cmd):
            out = {
                "decision": "deny",
                "reason": f"Plan Swarm Safety Firewall: {warning} Command blocked: '{cmd}'."
            }
            print(json.dumps(out))
            return

    print(json.dumps({"decision": "allow"}))

if __name__ == "__main__":
    main()
